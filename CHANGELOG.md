# Changelog

## Unreleased
- `omaprofile` in a terminal, or Omaprofile in the app launcher, opens a rules editor: see, add, change, reorder and delete the rules that skip the picker.

## 0.4.0
- Shift+Enter in the picker opens the link and remembers the profile for that site.

## 0.3.0
- Every web app asks for a profile, including ones added after install.
- An icon in the bar and a line in the picker say when a new version is out.
- `omaprofile update` shows what's new and updates through Omarchy.

## 0.2.0
- Installs as an Omarchy plugin, with setup and removal prompts.
